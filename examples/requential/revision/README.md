# Контрольные эксперименты для статьи о requential-кодировании

Извлеките содержимое архива в каталог `revision` внутри прежнего каталога `requential`, в котором лежат `run.py` и папка `results`. Откройте PowerShell в `requential`. Используйте прежнее окружение Python с NumPy и SciPy.

```powershell
python ./revision/check_controls.py
python ./revision/regular_pfr.py
```

## Шумный учитель

В `regular_matched.csv` каждое значение `q` (0,37 и 0,20) и порога ε (1/64 и 1/128 ната) задаёт отдельное сравнение. История из n наблюдений содержит k единиц, где k имеет распределение Bin(n,q). Из априорного распределения Beta(1,1) получаем однопозиционную вероятность ученика p=(1+k)/(2+n). Предложение из B меток имеет закон Bern(p) в степени B. Новый пакет от учителя имеет закон Bern(q) в степени B. После пакета обновляется вся история.

Первый объём N, при котором ожидаемая KL не превышает ε, определяется последовательным просмотром n начиная с нуля. Если начальная модель уже удовлетворяет порогу, длина равна нулю. Геометрический путь заканчивается укороченным пакетом при N. `pfr_dp` и `bound_dp` оптимизируют при фиксированном N фактическую ожидаемую длину слова и сумму верхних оценок соответственно. Сопоставляйте столбец `expected_pfr_bits` внутри одной пары (q, ε). `upper_bound_bits` хранит отдельную величину. Расписания публичны и детерминированы.

Для пакета x положим R(x)=Q(x)/P(x). Условно на выбранный пакет индекс геометрический со средним 1+Σ P(y) max(R(x)−R(y),0). Отношение зависит только от числа единиц s. Например, при q>p среднее равно R(s) Prₚ(S<s)+Pr_q(S≥s). Так можно усреднить длину δ-кода без генерации потенциально очень больших индексов. Формула условного закона взята из [Qiu et al., доказательство леммы B.2](https://arxiv.org/abs/2607.11883v1). Оба биномиальных закона усредняются численно после отсечения хвостов с массой до 10⁻¹⁴ с каждой стороны и нормировки. Хвост ряда для длины Элиаса отсекается при вероятности перехода через следующий учитываемый порог менее 10⁻¹⁶. Оценки детерминированы с точностью численного суммирования. Конечные точки дают проверку для этих параметров задачи. Вывод о пределе при ε→0 требует отдельного аргумента.

Параметры меняются, например, командой `python ./revision/regular_pfr.py --q 0.37 --epsilon 0.00390625 --cap 256`. При уменьшении ε число рёбер в поиске растёт квадратично с конечным N, а стоимость вычисления одного ребра также растёт.

## Восстановление конечной точки

`path_controls.csv` содержит отдельную строку на модель, начальное значение генератора и горизонт. `path_summary.csv` содержит средние и поточечные парные интервалы Стьюдента для выигрыша в битах. По умолчанию используются 48 начальных значений 2026–2073, горизонты 16, 64 и 128, учитель Bern(0,65) и допуск 0,001 ната. При каждом seed модель получает метки через собственный PFR. Четыре способа кодирования внутри одной строки используют одну цель и один общий поток кандидатов. Каждое сообщение декодируется, длина включает δ-заголовок для числа шагов плюс один.

| Столбец | Что измеряет |
|---|---|
| trajectory_bits | Исходный поток индексов PFR |
| same_labels_bits | Те же T меток в том же порядке, для каждой выбран первый допустимый индекс |
| suffix_bits | Последние min(T,h) меток, повторённые из начального состояния с шага 0 |
| shortest_bits | Минимум битов по всем допустимым путям в окрестность цели |

Параметр h выбирается по оценке (9/7)4⁻ʰ ≤ δ. При δ=0,001 достаточно шести меток. Для аффинной модели это строгая гарантия. Для сеточной модели и накопительного среднего измерена фактическая KL, а `suffix_feasible_fraction` показывает долю путей, уложившихся в допуск. Сравнение длины суффикса с оптимумом имеет смысл при выполненном допуске. Модель `mean` предсказывает (1+s)/(2+t) после s единиц за t шагов. В ней более ранние и более поздние метки на одном горизонте имеют одинаковый вес. Уменьшение длины при переходе от исходного потока к тем же меткам измеряет экономию при перекодировании, а последующий выигрыш включает всю свободу выбора пути до цели.

## Проверка прогноза для SGD

`sgd_fit_check.py` читает прежний `sgd.csv`. На контрольных точках 512–2048 шагов для каждой траектории подбираются свободный член и коэффициент каждой модели. В степенном семействе показатель β также выбирается на этом участке по сетке 0, 0,01, …, 1. При β=0 используется логарифм. Прогноз проверяется на точках 2048<T≤4096. В `sgd_fit_check.csv` различаются ошибка средней кривой и средняя ошибка отдельных траекторий. Интервалы рассчитаны по парным разностям последних отдельно для каждой конфигурации. Это ретроспективное сравнение на уже изученных траекториях.
