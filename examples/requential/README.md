В проекте исследуется, сколько битов нужно передать, чтобы воспроизвести обучение модели. Для модели Бернулли мы нашли размеры пакетов, при которых ожидаемая длина сообщения минимальна при заданной точности. В опытах с градиентным спуском проследили, как накапливается ошибка предсказания. На трёх простых моделях сравнили длину записи всей траектории с длиной кратчайшей последовательности, которая приводит модель к той же конечной точке с заданной точностью.
