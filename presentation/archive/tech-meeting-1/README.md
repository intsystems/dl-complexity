# Презентация проекта

Основная версия:

- [`dl_complexity_presentation.tex`](dl_complexity_presentation.tex) — англоязычный исходник Beamer;
- [`dl_complexity_presentation.pdf`](dl_complexity_presentation.pdf) — готовая англоязычная
  презентация 16:9 на 10–15 минут;
- [`SPEAKER_NOTES.md`](SPEAKER_NOTES.md) — подробные русскоязычные заметки докладчика:
  определения, разбор формул, переходы между слайдами и ответы на вероятные вопросы.

Стиль повторяет предоставленный пример: стандартная тема Beamer, синие заголовки, дефисы
вместо маркеров, нумерация кадров и минимальное количество декоративных элементов.

Сборка с помощью Tectonic:

```powershell
tectonic dl_complexity_presentation.tex
```

Презентация покрывает требования Tech Meeting 1: описание, scope и название проекта,
схему классов, интеграцию и стек, четыре слайда с алгоритмами, benchmark, PoC/демо,
распределение ролей и критерии контрольных точек.
