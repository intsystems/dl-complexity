# Теоретическая статья DL Complexity

Текст статьи — [main.pdf](main.pdf). LaTeX-исходник — [main.tex](main.tex). Статья исследует стоимость requential-записи обучения, влияние размеров пакетов и предиктива, накопленный риск факторизованной регрессии и короткое описание конечной модели.

Объяснение с нуля по разделам и короткий рассказ для выступления — [article_guide.md](article_guide.md).

В тексте есть введение, обзор литературы, формальная постановка, доказательства, численные примеры и обсуждение.

## Основные результаты

- Для нулевого учителя и априорного распределения `Beta(a,b)` оптимальная ожидаемая стоимость замороженного протокола равна `A(a) ln(1/ε) + O(1)`. Геометрическое расписание достигает ведущего коэффициента.
- Получена ведущая константа при ограничении среднего числа кандидатов на пакет.
- Совместный байесовский предиктив пакета даёт другую ведущую константу — `a/ln(2)`, строго меньшую `A(a)`.
- Доказана классификация точного градиентного спуска с шагом `γ/(t+t₀)`, включая сбалансированный случай с накоплением риска порядка `T/ln²(T)`.
- Для сжимающего ученика построено описание конечного состояния длины `O(ln(1/δ))`, не зависящей от горизонта исходного обучения.

Теоремы о длине записи относятся к протоколу с обязательным отдельным индексом на пакет. Классификация факторизованной регрессии доказана для точного популяционного градиента; стохастический градиентный спуск разобран отдельно для скалярной модели.

## Воспроизведение расчётов

Из корня `dl-complexity`:

```powershell
python -m pip install -r theory/requirements.txt
python theory/reproduce.py
```

Скрипт работает на CPU и не скачивает данные. Он пересоздаёт `generated/results.json`, таблицу коэффициентов и рисунок в PDF/PNG. Проверки входят в этот же запуск: прямое суммирование распределения индекса, полный перебор маленьких задач, сертификат динамики и перебор суффиксов. Ненулевой код выхода означает, что одна из проверок не прошла. На проверенном окружении запуск занимает несколько секунд; точные версии записаны в JSON.

## Сборка PDF

Нужны Tectonic либо XeLaTeX с BibTeX. В документе используются шрифты GNU FreeFont, включая кириллицу; TeX-дистрибутив должен содержать файлы `FreeSerif.otf`, `FreeSerifBold.otf`, `FreeSerifItalic.otf`, `FreeSerifBoldItalic.otf`, `FreeSans.otf`, `FreeSansBold.otf`, `FreeSansOblique.otf`, `FreeMono.otf`. Tectonic загружает их автоматически при первой сборке.

```powershell
cd theory
tectonic main.tex
```

Альтернатива:

```powershell
cd theory
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

PDF уже собран Tectonic 0.17.0. Временные инструменты для чтения и сборки не входят в проект. Для сборки исходного текста пересчёт примеров не обязателен: используемые таблица и рисунок сохранены рядом с рукописью.
