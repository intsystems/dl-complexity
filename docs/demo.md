# Воспроизводимая демонстрация

## Общий интерфейс

После [установки](installation.md) запустите из корня репозитория:

```bash
python examples/quickstart.py
```

Пример показывает AIC/BIC/HQIC, двухчастный код и статистики весов.
Отсутствие posterior для WAIC отражается как `MISSING_INPUTS`.
Модель с нулевыми весами служит демонстрацией API, её оптимальность не заявляется.

## Prequential coding на MLP

{download}`Скачать полный исполняемый пример <../examples/prequential_demo.py>`.
При сборке Sphinx файл включается в HTML-сайт; скачивание работает и до
публикации изменений в GitHub.

```bash
python examples/prequential_demo.py
python examples/prequential_demo.py --json docs/_build/prequential-demo.json
```

Один CPU-пример обучает MLP `2 → 8 → 2` с `tanh` в `float64` на синтетической
бинарной классификации. Данные создаются локально, скачивания не нужны.
Все шесть запусков получают одинаковые данные, порядок и начальные веса.

| Настройка по умолчанию | Значение |
|---|---|
| Число наблюдений / seed данных | 192 / 7 |
| Начальный равномерный префикс | 16 наблюдений = 16 битов |
| Blockwise-границы | `[16,32,64,128,192]` |
| Бюджет blockwise | 80 полных gradient steps на каждом прошлом префиксе |
| Online/replay | Новый блок 16, по 10 gradient steps после раскрытия |
| Replay | До 32 объектов из раскрытого префикса, seed 9 |
| Обучение | Adam, learning rate 0.03 |
| Калибровка | Отдельный положительный scalar T, 15 Adam steps на обновление |

Это сопоставление протоколов, у которых различается бюджет обучения;
оно не является сравнением при равном числе FLOPs или одинаковом времени.

Вывод содержит шесть строк: blockwise, online, replay, каждый с калибровкой
и без неё. Столбцы:

- `total_bits`: стоимость всей последовательности;
- `initial_bits`: равномерный начальный префикс;
- `predictive_bits`: остальная стоимость;
- `bits/obs`: полная стоимость, делённая на `n`.

Равномерный код бинарных меток стоит ровно `n` битов. Значение ниже этой линии
показывает выигрыш относительно фиксированного равномерного предиктора для
данного опыта. Значение выше допустимо: обучение и калибровка могут быть неудачны.
Строгое ранжирование методов и универсальный выигрыш калибровки не предполагаются.

Пример полученного вывода с настройками выше, PyTorch `2.14.1+cpu`:

| Протокол | Калибровка | Total bits | Bits / observation |
|---|---|---:|---:|
| Blockwise | Нет | 129.9731 | 0.6769 |
| Blockwise | Да | 150.7168 | 0.7850 |
| Online | Нет | 136.7170 | 0.7121 |
| Online | Да | 130.7332 | 0.6809 |
| Replay | Нет | 119.5394 | 0.6226 |
| Replay | Да | 126.8715 | 0.6608 |

Здесь начальная часть каждой строки равна 16 битам, а равномерный baseline —
192 битам. Калибровка улучшила online, но ухудшила два других протокола.
Это один seed и заданные бюджеты, а не статистически установленное преимущество.
Тесты проверяют тождества и причинность; точные обученные значения из таблицы
не закреплены как универсальный эталон для других версий окружения.

## Конфигурация и артефакт

Параметры доступны через `--help`. Например:

```bash
python examples/prequential_demo.py --n 256 --seed 11 --initial-count 16 --batch-size 16 --replay-size 32 --json docs/_build/prequential-seed11.json
```

JSON хранит `config`, seeds инициализации/replay, версию Torch, device/dtype,
baseline, шесть результатов, provenance, время и полные журналы интервалов.
`initial_nll` и `entries[].nll` остаются в натах; итоговые столбцы — в битах.
Проверяемое тождество для каждой строки:

$$
\texttt{total\_bits} = \texttt{initial\_bits} + \texttt{predictive\_bits}
 = \frac{\texttt{initial\_nll} + \sum_e e.\texttt{nll}}{\ln 2}.
$$

`elapsed_seconds` включает подготовку, обучение и оценку журнала, но не общую
генерацию данных. Времена меняются между запусками. Совпадение результатов
ожидается в одном CPU-окружении; побитовое совпадение между версиями Torch
и разными устройствами не гарантируется.

Демо не создаёт файлы без `--json`. Оно не использует test-метки; test NLL
и generalization gap должны добавляться отдельным исследовательским протоколом.
Пошаговое объяснение callbacks: [руководство](prequential.md).

## Другие примеры

`python examples/waic_wbic_mlp.py` сравнивает AIC/BIC с WAIC/WBIC на
teacher–student MLP и запускает MALA. Это отдельный, более дорогой пример.
Публичные сигнатуры подготовки выборок доступны в [API](api/integrations.rst).
